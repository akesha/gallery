# Teaching & AI in the Luddy Classroom — Selected Work

A curated gallery of Dr. Akesha Horton's teaching-and-AI work at Luddy: faculty programs
and workshops, guides and resource hubs, student-facing AI tools and essays, and
interactive tutorials built for class. Every thumbnail links to the live page.

`index.html` is self-contained (thumbnails are embedded), regenerated by `build_curated.py`.
